# agent-team-kit — instrucciones para agentes de IA

Este repo contiene dos skills (`team-bootstrap`, `team-resume`) para que tres agentes de IA trabajen como equipo coordinados por Herdr.

- **Para instalar o usar el repo**, sigue la sección **"9. Instrucciones para agentes de IA"** de `README.md`.
- No ejecutes las skills por tu cuenta: solo corren cuando el usuario las invoca.
- No modifiques configuraciones del usuario (perfil de shell, configs MCP de otros agentes) sin preguntar.
- Si cambias algo en `skills/`, vuelve a correr el instalador (`install.ps1` en Windows, `install.sh` en macOS/Linux).
